# Mission: practical Go, from a CLI quiz to an HTTP API

## Why
Become autonomous in Go in 3–6 months by using a concrete project rather than isolated exercises: a quiz that starts in the terminal and grows into a small HTTP API. The result should make it possible to build and confidently discuss Go CLI tools and backend services.

## Success looks like
- Create, test, and distribute a small Go CLI for a quiz.
- Model the quiz domain and evolve it into an HTTP API with the standard library.
- Read idiomatic Go, debug it, and handle the foundations expected in an entry-level interview.

## Constraints
- The Student writes most of the code; the Tutor offers hints, feedback, and reviews.
- Keep lessons and teaching references short, practical, and progressive in Markdown only, directly readable in the IDE; never create HTML learning material; ask only one question at a time.
- *Learning Go* is a freely consulted resource: every activity suggests keywords without imposing the book's order.
- Language: English, both in repository material and tutoring conversations.
- Environment: macOS on Apple Silicon, Go 1.26.5, GoLand, and Git.

## Out of scope
- A complete frontend, payments, and a production-ready public product.
- Databases, authentication, deployment, and advanced concurrency until the quiz needs them.

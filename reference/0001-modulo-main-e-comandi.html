Modulo, main e primi comandi

Modulo
Unità di versione e dipendenze di un progetto Go. Il file go.mod ne dichiara il percorso.
package main
Package che produce un programma eseguibile.
func main()
Punto da cui inizia l'esecuzione del programma.

Ciclo minimo

go mod init github.com/ACCOUNT/REPOSITORY
go run ./quiz

Il percorso del modulo è il suo futuro percorso di importazione: quando il codice vive in un repository, usa l'URL del repository senza https:// né .git. Con go.mod alla radice e il comando go run ./quiz, compili ed esegui il package nella cartella quiz. Useremo go build nel prossimo passo, scegliendo esplicitamente dove mettere l'eseguibile.

Forma minima di un programma

package main

import "fmt"

func main() {
    fmt.Println("...")
}

Il compilatore richiede che ogni import sia davvero usato. Per ora basta ricordare che fmt.Println stampa una riga sullo standard output.

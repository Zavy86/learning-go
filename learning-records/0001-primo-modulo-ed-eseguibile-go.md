# Primo modulo ed eseguibile Go

Lo Studente ha creato il modulo `github.com/Zavy86/learning-go` alla radice del repository e ha eseguito con successo `go run ./quiz`, ottenendo `Benvenuto nel quiz!`. Questo dimostra il primo ciclo di lavoro Go: modulo alla radice, package `main` in una sottocartella ed esecuzione tramite percorso del package.

## Evidence

Esecuzione verificata il 2026-08-20 con output corretto.

## Implications

Il prossimo passo può introdurre la distinzione pratica fra `go run` e `go build`, poi gli argomenti della riga di comando per rendere il quiz una CLI.

# First Go module and executable

The Student created the `github.com/Zavy86/learning-go` module at the repository root and successfully ran `go run ./quiz`, obtaining `Welcome to the quiz!`. This demonstrates the first Go development cycle: module at the root, a `main` package in a subdirectory, and execution through a package path.

## Evidence

Execution was verified with correct output on 2026-08-20.

## Implications

The next step can introduce the practical distinction between `go run` and `go build`, then command-line arguments to turn the quiz into a CLI.

# Learning Go from scratch: CLI quiz → API

## Destination

Within 3–6 months, master Go fundamentals by personally building a quiz that evolves from a CLI into an HTTP API, gaining foundations useful for interviews and backend projects.

## Notes

The Student is experienced with Node.js, TypeScript, and Git. The Practical Tutor proposes goals and exercises, gives hints, clarifies doubts, and reviews code; the Student writes most of the code.

The book *Learning Go* is a freely consulted theoretical source: every task lists topics and keywords to look up without necessarily following its order. First build a CLI, then an API with the standard library. Exception to Wayfinder mode: this map includes execution-oriented learning tasks explicitly requested by the Student.

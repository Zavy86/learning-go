# Imparare Go da zero: quiz CLI → API

## Destination

In 3–6 mesi, padroneggiare i fondamenti di Go costruendo in prima persona un quiz che evolve da CLI a API HTTP, con basi utili anche per colloqui e progetti backend.

## Notes

Lo Studente è esperto di Node.js, TypeScript e Git. Il Tutor pratico propone obiettivi ed esercizi, dà indizi, chiarisce dubbi e revisiona il codice; lo Studente scrive la maggior parte del codice.

Il libro *Learning Go* è una fonte teorica libera: ogni task indicherà argomenti e parole chiave da cercarvi, senza seguirne necessariamente l'ordine. Prima si costruisce una CLI, poi un'API con la libreria standard. Eccezione alla modalità Wayfinder: questa mappa include task esecutivi di apprendimento, esplicitamente richiesti dallo Studente.

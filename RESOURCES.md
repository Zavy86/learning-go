# Go resources

## Knowledge

- [Documentazione ufficiale Go — Tutorial: Create a Go module](https://go.dev/doc/tutorial/create-module)
  Primary source for creating a module, writing `main`, and running a first program. Use it in the initial lessons.
- [Documentazione ufficiale Go — Command `go`](https://pkg.go.dev/cmd/go)
  Authoritative reference for `go run`, `go build`, `go test`, and modules; useful when a command behaves unexpectedly.
- [Specifica del linguaggio Go](https://go.dev/ref/spec)
  The normative source for syntax and semantics; consult it for precise questions, not as linear reading at the beginning.
- [Jon Bodner, _Learning Go_](https://www.oreilly.com/library/view/learning-go/9781098139285/)
  The Student's chosen text: search for keywords suggested after each exercise, in the order that serves the project.

## Wisdom (Communities)

- [Go Forum](https://forum.golangbridge.org/)
  A Go-focused community: useful for asking for a reasoned review or comparing solutions after attempting an exercise.
- [Gophers Slack](https://gophers.slack.com/)
  A broad Go practitioners' community; useful later to discuss conventions and concrete problems.
